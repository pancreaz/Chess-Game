# Chess-Game
A 2-Player Local 2D Chess Game built in C# (.NET 9 Windows Forms).

Featuring a top-down view, vector-rendered 2D chess pieces, move highlighting, checkmate/check warnings, and move validation.

<img width="1920" height="1017" alt="Screenshot (307)" src="https://github.com/user-attachments/assets/7ea0fd7e-b8cd-4916-8112-5acf3328116d" />

# Features :

<ul type="circle">
  <li>High-DPI, anti-aliased 2D vector-rendered chess pieces</li>
  <li>Provides visual and audio feedback for important game events</li>
  <li>The UI tracks : 
    <ol>
      <li>Captured White and Black Pieces</li>
      <li>Material Advantage/Difference</li>
    </ol>
  </li>
  <li>Use Undo Move to step back through the game</li>
  <li>An automated test suite (Launch using "dotnet run -- --test" in cmd)</li>
</ul>

# Run on local computer :

## Steps :
  1. Download folder
  2. Open cmd inside the chess folder
  3. run "dotnet run"
  4. Enjoy!
